## Project Overview
Hostel administration requires a geo-tagged ticketing pipeline to report plumbing, electrical, and carpentry issues, dispatch maintenance staff, track SLA timelines, and record resident closure sign-offs.

### Key Stakeholders and Actors
- **Hostel Resident**: Logs tickets with room tags and photos; reviews repairs and provides closure sign-off or reopen requests.
- **Maintenance Warden**: Reviews pending issues, triages tickets, assigns technicians, monitors SLA timers and escalations.
- **Maintenance Staff**: Receives repair work orders, executes repairs, and uploads geo-tagged proof-of-work photos upon completion.
